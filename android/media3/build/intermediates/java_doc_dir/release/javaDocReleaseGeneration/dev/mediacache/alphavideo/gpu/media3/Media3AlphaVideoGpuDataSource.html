Class Media3AlphaVideoGpuDataSource

  • All Implemented Interfaces:
    dev.mediacache.alphavideo.gpu.AlphaVideoGpuDataSource 
    
public final class Media3AlphaVideoGpuDataSource
 implements AlphaVideoGpuDataSource

    An AlphaVideoGpuDataSource over a Media3 DataSource, so that the player reads through the app's {@code DataSource.Factory}: OkHttp, Cronet, a {@code CacheDataSource}, or MediaCache's. Register one for React Native: 

    AlphaVideoGpuDataSources.register("media3", Media3AlphaVideoGpuDataSource.factory(dataSourceFactory));
    Media3 sources can't be cancelled, so a read in progress when the player closes finishes in the background. A source without a total size or an ETag in its response headers (a cache, a file) still plays; the player's store just can't tell when it changes.
